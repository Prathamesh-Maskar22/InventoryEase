# 📦 InventoryEase

**InventoryEase** is a lightweight, user-friendly product management system designed to streamline inventory tasks such as adding, updating, and tracking products. Built with React and Node.js, this full-stack application provides a clean interface and essential features for managing product data with ease.

---

## 🔧 Features

- ➕ Add new products with name, price, and barcode
- 🛠️ Edit existing product details
- 🔍 Fetch product data via dynamic route (e.g., `/products/:id`)
- 🔒 Input validations and barcode length restriction (max 12 digits)
- 🚀 Smooth update flow with loading states and error handling
- 💻 Clean, responsive UI using Bootstrap

---

- **Backend**: Node.js, Express.js

## To Run App:

### 1. Open the folder in vs code and run (npm install) command.
   
### 2. In MongoDB Compass:
   - Create Database: IMS
   - Collection Name: products

### 3. In one terminal run these commands (For Backend / Server):
   - cd Backend
   - npm run server

### 4. In the other terminal run these commands (For Frontend / Client):
   - cd Frontend
   - cd inventory_management_system
   - npm start
